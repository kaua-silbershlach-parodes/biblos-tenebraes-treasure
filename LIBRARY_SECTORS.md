## PDF types

Of the 626 PDFs in the library, measured by extracting text from the first
pages of each file:

- **551 text PDFs** — native, machine-readable text; these feed the engine
  directly.
- **74 scanned/image PDFs** — page images without a text layer; these need
  OCR before they can feed the engine.
- **1 unreadable PDF** — the file could not be opened.

The engine starts from the smallest text book in the library and grows one
book at a time, in the same sector order above.
